# 🐃 oxherd - 移动端流体物理动效值班打卡应用

> 基于现代 WebView 与 Android 原生容器技术栈，深度融合**《流体物理动效系统设计规范 (Fluid Motion Design Specification)》**打造的高保真、高可靠值班打卡与巡检助理。

---

## 🌟 核心特性全景

### 1. 🎯 岗位在设置中切换（核心需求）
- **顶栏专属入口**：主界面顶栏显著展示当前值班岗位（如 `📍 3楼 社科阅览室与借阅区 [2/3已核验]`）。
- **设置面板一键切换**：点击顶栏或设置按钮，唤起流畅的「岗位设置与切换」抽屉：
  - 直观列出当前值班的所有岗位（3楼、4楼、5楼等），标注核验进度与当前激活状态；
  - 点击任意岗位即刻完成切换，条目列表伴随流体动效平滑切换；
  - 支持快捷「+ 新增岗位」及岗位重命名。

### 2. 👆 任务条目、子条目与手势滑动划去 (Swipe-to-Complete)
- **手势物理弹性阻尼**：手指水平右滑超过 75px 阈值，触发轻触感震动；释放时播放文字删除线穿透动画与微落定。
- **子条目树状层级**：每个条目可包含多条细分子条目（如消火栓压力表、应急指示灯等），支持一键展开/折叠（基于 Freeze-Inner Geometry 容器补间，零重排拉伸）。
- **3秒防误触撤销**：划去后底部自动弹出 Undo Toast，可随时撤回。

### 3. 📷 拍照巡查、归类整理与自动打包归档
- **条目拍照配置**：在岗位设置中，可为每个条目独立开关 **「📷 巡检要求拍照」**。若未拍照会有醒目标签提示。
- **巡查文件归类整理**：拍摄的现场照片自动按 `[岗位]_[条目名称]_[时间戳].jpg` 规范分类命名，卡片内支持缩略图预览与一键 **「📋 复制凭证」**（快速填报单位值班链接）。
- **交班自动打包归档**：
  - 底部提供 **长按 1.5 秒物理蓄力交班按钮**（防误触）；
  - 确认后自动生成 `值班归档_[任务名]_[日期].zip` 压缩包并自动触发下载；
  - 压缩包内含完整的 `duty_summary.md` 交班报告、`duty_data.json` 结构化数据和按岗位分目录归档的现场照片；
  - **归档并刷新**：交班完成后工作台自动清爽复位，立即就绪下一次值班！

### 4. 🔔 通知唤醒全参数自定义
- **通知总开关**：随时开启或静默通知；
- **提前预警量**：支持灵活选择 5 分钟、10 分钟、15 分钟、30 分钟或 60 分钟；
- **唤醒提示音**：支持独立开关高优先级警报声音（静音模式下也能发声）；
- **巡更强震动**：支持独立开关交替长震动模式（`0-500-200-500-200-800` 脉冲）；
- **时段巡查开始提醒**：到达每个时段起点时自动触发打卡提醒；
- **一键测试通知**：设置页提供「测试通知提醒」按钮，点击立即弹出发声强震动通知，直观检验效果。

### 5. ⚡ 开机自启动与后台保活（确保通知必达）
- **开机自恢复广播 (`DutyBootReceiver`)**：
  - 声明 `RECEIVE_BOOT_COMPLETED` 权限；
  - 设备重启或应用更新后，若开启「开机自启恢复调度」，自动读取数据库中尚未过期的值班任务，在后台无感向 `AlarmManager` 重新注册精确唤醒闹钟 (`AlarmManager.setExactAndAllowWhileIdle`)，杜绝关机重启后提醒丢失。
- **系统级保活与自启动助手 (`KeepAliveHelper`)**：
  - **电池优化白名单**：实时检测电池优化状态，提供一键申请加入白名单（`ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`），杜绝系统 Doze 深度休眠杀停闹钟；
  - **主流厂商自启动跳转**：内置针对小米/HyperOS、华为/HarmonyOS、OPPO/ColorOS、vivo/OriginOS 等系统的自启动与后台保护快捷 Intent，用户点击即可直达系统设置开启自启动白名单。

### 6. 🎨 深浅色模式与跟随系统
- 支持 **☀️ 浅色模式**、**🌙 深色模式** 及 **💻 跟随系统**。
- 深度集成动效规范中的 **场景 7 主题墨滴扩散与波前下扫 (`themeSwitch`)**，切换顺滑自然。

### 7. 📋 值班模板库
- 内置开箱即用的示范模板：
  - **图书馆常规值班巡视**（包含 3楼社科阅览、4楼电子阅览与自习、5楼古籍特藏，预设消防、温控与读者秩序等子条目）；
  - **实训中心与数据机房日班巡检**（包含配电UPS室、服务器机柜区等）；
- 支持一键从模板秒级生成新值班任务，也支持随时创建空白临时值班。

## 🛠️ 技术架构

```
oxherd/
├── src/
│   ├── engine/                     # 流体物理动效核心引擎 (WAAPI / 15 组贝塞尔 / 状态机)
│   │   ├── motion-tokens.css       # 物理曲线与时长令牌
│   │   ├── motion-engine.js        # 数值贝塞尔求解器与姿态生成器
│   │   ├── motion-components.js    # 连续滑块、实心高光、3D铰链与长按蓄力
│   │   └── fluidMotion.ts          # TypeScript 强类型封装
│   ├── models/
│   │   └── types.ts                # Task / Post / Item / Photo / Settings 数据契约
│   ├── storage/
│   │   └── db.ts                   # 离线持久化、示范模板库与 JSZip 自动归档
│   ├── gestures/
│   │   └── swipeTracker.ts         # 弹性阻尼横滑划去手势追踪器
│   ├── services/
│   │   └── nativeBridge.ts         # Android 原生与 Webview 双向通信桥接服务
│   ├── components/
│   │   └── modals.ts               # 岗位切换、系统设置、交班报告与模板库模态框
│   ├── styles/
│   │   └── app.css                 # 移动端全响应式与深浅色模式样式表
│   └── main.ts                     # 应用入口与控制器
├── android/                        # Android Capacitor 原生工程
│   └── app/src/main/java/com/oxherd/app/
│       ├── MainActivity.java       # 原生插件注册入口
│       ├── OxherdPlugin.java       # Capacitor 原生插件 (闹钟/通知/保活/厂商跳转)
│       ├── KeepAliveHelper.java    # 电池优化检测与各大厂商自启动 Intent 直达
│       ├── AlarmReceiver.java      # 高优先级响铃与巡更强震动广播接收器
│       └── DutyBootReceiver.java   # 开机自启与应用更新恢复闹钟广播
├── package.json
└── vite.config.ts
```

## 🚀 运行与构建指南

### 1. 本地网页实时预览
```bash
# 启动 Vite 本地开发服务器
npm run dev

# 浏览器访问 http://localhost:3000 即可进行全功能交互与手势测试
```

### 2. 生产环境构建与资源同步
```bash
# 构建前端产物
npm run build

# 同步前端代码至 Android 原生工程
npx cap sync android
```

### 3. 构建 Android APK
```bash
# 进入 android 目录并执行 Gradle 构建
cd android
./gradlew assembleDebug

# 生成的安装包路径：
# android/app/build/outputs/apk/debug/app-debug.apk
```
或直接使用 **Android Studio** 打开 `android` 目录，连接真机或模拟器点击运行。
